Add an isolated `@xgc2/ui-workflow/graph` entry for the Graphite Atlas foundation:
controlled graph selection, bounded projections, a version-pinned context payload,
resource inspector, accessible list navigation and an injected Cytoscape adapter.
The new entry does not import React Flow and does not bundle a graph engine.
Existing workflow imports and the shared stylesheet entry remain compatible.
