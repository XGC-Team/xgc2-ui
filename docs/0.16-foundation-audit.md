# XGC2 UI 0.16 Foundation Audit Scope

The foundation reset is expected to audit these primitives before broad downstream rollout:

1. Button and icon-button geometry/state treatment
2. Input, number input, textarea and select geometry
3. Tabs, segmented control and workspace tabs
4. Panel and workspace panel surfaces
5. App shell, sidebar and topbar chrome
6. Form field/group hierarchy
7. List rows, data tables and pagination
8. Drawer, modal, popover and tooltip overlays
9. Focus-visible and keyboard interaction
10. Dark/light token parity and reduced-motion behavior

Advanced packages should not compensate for unresolved defects in these primitives.
