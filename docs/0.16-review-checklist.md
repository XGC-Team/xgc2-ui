# XGC2 UI 0.16 Review Checklist

Every core primitive promoted to stable in the 0.16 line should be reviewed against the same checklist.

## Visual

- Clear hierarchy without relying on decorative borders or shadows.
- Consistent text baseline, icon alignment, padding, and perceived control height.
- Dark and light surfaces preserve the same semantic hierarchy without mechanical inversion.
- Long labels, empty values, and dense content do not distort geometry.

## Interaction

- Hover, active, focus-visible, selected, disabled, loading, and destructive states are visually distinct and continuous.
- Keyboard behavior is complete and documented.
- Pointer targets remain usable in compact density.
- Reduced-motion behavior preserves all state changes without unnecessary animation.

## Composition

- The primitive composes correctly in toolbars, panels, drawers, tables, forms, and workbench chrome.
- Nested surfaces stay visually quiet.
- Product CSS is not required to repair the primitive's default appearance.

## Performance

- No avoidable layout thrashing on pointer or streaming updates.
- Heavy children can be lazily mounted by consuming packages.
- Large lists/timelines have a virtualization path.
- CSS effects are progressive enhancement rather than correctness dependencies.

## Accessibility

- Focus indication is unambiguous.
- State is never communicated by color alone.
- Screen-reader semantics match visible interaction.
- Zoom and compact viewports remain usable.
