# XGC2 0.16 Advanced Interaction Layer

The advanced layer is intentionally built after the foundation reset. Its purpose is to provide reusable workbench capabilities for XGC2 GCS, Research, Agent Hub, and future products without moving product-domain authority into the UI packages.

## Planned capability packages

### Conversation

A future `@xgc2/ui-conversation` package should provide a streaming, virtualized human/agent timeline rather than a simple chat bubble stack. The shared layer owns event rendering, follow-tail behavior, composer interaction, activity grouping, approvals, citations, attachments, and keyboard behavior. Products own transport, permission checks, persistence, and domain semantics.

### Workbench

A future `@xgc2/ui-workbench` package should provide multi-resource editing mechanics: resource explorer, quick open, command palette, editor tabs/groups, split panes, dirty state, diff presentation, inspector, bottom panels, and persistent layout state. Products supply resource adapters and domain-specific commands.

### Manuscript

`@xgc2/ui-manuscript` remains the heavy research/document sibling package. The next target is a cohesive source/PDF workspace with search, page navigation, text selection, quote context, source/PDF navigation, and agent-reference affordances.

### Workflow

`@xgc2/ui-workflow` continues to own spatial editing mechanics. Its visual chrome should converge on the 0.16 foundation while node/edge domain bodies remain product-owned.

## Interaction principles

- Prefer contextual actions over permanently visible button walls.
- Prefer structured activity over decorative status cards.
- Make keyboard navigation first-class.
- Preserve operator cursor stability in dense control surfaces.
- Treat files, documents, robots, experiments, runs, and work items as resources that can participate in the same workspace mechanics.
- Keep heavy capability dependencies out of the base React package.
