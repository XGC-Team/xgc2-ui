# XGC2 UI 0.16 Package Boundaries

## Base package

`@xgc2/ui-react` stays dependency-light. It owns themes, tokens, shell, forms, tables, overlays, resource-list patterns, conversation presentation primitives that do not require a streaming runtime, and general layout mechanics.

## Heavy capability packages

- `@xgc2/ui-manuscript` owns Monaco/PDF.js-based research editing surfaces.
- `@xgc2/ui-workflow` owns spatial workflow editing mechanics.
- Future `@xgc2/ui-conversation` may own virtualization and streaming event presentation when the behavior exceeds the base package's lightweight primitives.
- Future `@xgc2/ui-workbench` may own editor-group, resource explorer, command surface, and docking mechanics.

No package owns product API clients, authentication, authorization, domain validation, persistence, or resource semantics.
