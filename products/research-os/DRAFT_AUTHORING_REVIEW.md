# Project object authoring — F1

Implementation and acceptance authority: [FRONTEND_REVIEW.md](./FRONTEND_REVIEW.md).

The earlier unpublished F1c package is integrated here with the F1.1–F1.5 completion work. It is not a separate app, branch baseline or accepted runtime.

`research-drafts.json` contains project-owned material references, source notes and six artifact/method draft kinds. All carry stable IDs and retain source/extension fields. One book tab owns the serialized conditional-write session. List and card displays edit the same blocks. Archive/restore preserves objects; it does not delete sources or stop existing workflows. Knowledge-promotion requests remain suggestions, not automatic global writes.

The actual text file API, PDF intake API, native Chat and existing workflow/PDF surfaces are retained. The intake receipt queue is transient; the project book and successfully uploaded text files are server-stored. A local editing snapshot is not proof of successful saving or execution.

Use the validation commands, real-service scenario and explicit unverified boundaries in `FRONTEND_REVIEW.md`. Neither the previous patch bundle nor a PR submission closes F1 product acceptance by itself.
